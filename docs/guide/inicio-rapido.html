Bienvenido a rdd

Framework REST DDD para Rust

Construye APIs robustas con ergonomía de NestJS y minimalismo de Rust.

Ver CLI Ver especificación 

/// Tu primera aplicación rdd

use rdd::prelude::*;

#[service]
pub struct TaskService {
    repo: Repo,
}

#[aggregate(table = "tasks")]
pub struct Task {
    #[id]
    pub id: Uuid,
    pub title: String,
    pub done: bool,
}

#[controller("/tasks")]
impl TaskController {
    #[get("/")]
    async fn list(svc: TaskService) -> Result> {
        svc.list().await
    }

    #[post("/")]
    async fn create(svc: TaskService, body: Json) -> Result {
        svc.create(body.title.clone()).await
    }
}

#[rdd::main]
async fn main() -> Result<()> {
    App::new()
        .module(modules::tasks::module())
        .run("0.0.0.0:3000")
        .await
}

Pasos para crear tu primera API

1

Instalar la CLI

Linux o macOS, sin privilegios de administrador:

curl -fsSL https://jhonwick20262027-boop.github.io/rukito/install.sh | sh

Windows, desde PowerShell:

powershell -NoProfile -Command "iex (irm 'https://raw.githubusercontent.com/jhonwick20262027-boop/rukito/main/docs/install.ps1')"

Los dos comandos verifican el SHA256 del binario antes de instalarlo. Con una toolchain de Rust también sirve cargo install rdd-cli. Opciones, binarios y diagnóstico: guía de instalación.

2

Crear un proyecto

rdd new mi-api
cd mi-api
3

Generar un módulo

rdd g module tasks
4

Escribir tu dominio

Define tus aggregates, services y repositories en src/modules/tasks/

5

Migrar y ejecutar

rdd migrate
cargo run

Ejemplo completo

El comando rdd new genera una estructura completa como la descrita en la especificación técnica, incluyendo:

  • Módulo tasks con dominio, casos de uso, adaptador y controller en cuatro capas
  • Controlador HTTP con rutas GET /tasks y POST /tasks
  • /health y middleware CORS listo para configurar con rdd-cors
  • SQLite local como base de datos predeterminada y migrations/0001_tasks.sql; rdd migrate crea la base, o usa --memory para no tener ninguna
  • tests/acceptance.rs que recorre los códigos de error de §10.3

Comandos útiles

  • rdd new - Crear proyecto nuevo
  • rdd g module - Generar módulo
  • rdd run - Ejecutar la aplicación
  • cargo check - Verificar compilación
  • cargo test - Ejecutar tests
