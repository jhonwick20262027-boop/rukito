Instalar rdd

La CLI rdd crea proyectos, genera módulos y aplica migraciones. Se instala de tres maneras: con el instalador de una línea —sin Rust—, con un binario de la release, o compilándola con cargo. Las tres dejan el mismo ejecutable y no piden privilegios de administrador.

Elige un método

MétodoRequiereCuándo usarlo
Instalador de una líneacurl y tar (Unix) o PowerShell (Windows)La vía recomendada: descarga, verifica el SHA256 y deja rdd en un directorio de usuario; avisa si falta en el PATH.
Binario de la releaseNada adicionalInstalaciones controladas, sin conexión a la API de GitHub o con verificación manual.
cargo install rdd-cliRust 1.94 o superiorYa tienes toolchain, o tu plataforma no tiene binario precompilado.

Los binarios se publican para estas plataformas:

ObjetivoSistemaArchivo
x86_64-unknown-linux-gnuLinux x86_64 (glibc 2.35+)tar.gz
aarch64-unknown-linux-gnuLinux ARM64tar.gz
x86_64-apple-darwinmacOS Intel (11+)tar.gz
aarch64-apple-darwinmacOS Apple Silicon (11+)tar.gz
x86_64-pc-windows-msvcWindows x64zip

Cada archivo se llama rdd-<versión>-<objetivo> y contiene el ejecutable y la licencia. La release incluye además SHA256SUMS.txt con el hash de cada archivo.

Instalador de una línea

En Linux o macOS:

curl -fsSL https://jhonwick20262027-boop.github.io/rukito/install.sh | sh

En Windows, desde PowerShell:

powershell -NoProfile -Command "iex (irm 'https://raw.githubusercontent.com/jhonwick20262027-boop/rukito/main/docs/install.ps1')"

El instalador detecta el sistema y la arquitectura, resuelve la última release (o la que indiques), descarga el archivo y su checksum, compara el SHA256 antes de extraer, copia el ejecutable a un directorio de usuario y ejecuta rdd --version para confirmar que funciona.

Si prefieres revisarlo antes de ejecutarlo, descarga el script, léelo y ejecútalo desde el archivo:

curl -fsSL -o install.sh https://jhonwick20262027-boop.github.io/rukito/install.sh
less install.sh
sh install.sh

En Windows el script es el mismo que sirve el repositorio, entregado como texto plano para que iex lo evalúe:

irm https://raw.githubusercontent.com/jhonwick20262027-boop/rukito/main/docs/install.ps1 -OutFile install.ps1
Get-Content install.ps1
.\install.ps1

Opciones del instalador

Variable (Unix)Parámetro (Windows)Por defectoEfecto
RDD_VERSION-Versionúltima releaseVersión a instalar, con o sin v (p. ej. v0.1.0).
RDD_INSTALL_DIR-InstallDir~/.local/bin / %LOCALAPPDATA%\rdd\binDirectorio donde queda el ejecutable.
# Linux o macOS: fijar versión y destino
RDD_VERSION=v0.1.0 RDD_INSTALL_DIR="$HOME/bin" \
  sh -c "$(curl -fsSL https://jhonwick20262027-boop.github.io/rukito/install.sh)"
# Windows: equivalente desde PowerShell
$env:RDD_VERSION = 'v0.1.0'
$env:RDD_INSTALL_DIR = "$HOME\bin"
iex (irm 'https://raw.githubusercontent.com/jhonwick20262027-boop/rukito/main/docs/install.ps1')

En Windows el instalador añade el directorio al PATH del usuario; hay que abrir una terminal nueva para que el cambio se vea. En Unix, si el directorio no estaba en el PATH, el script imprime la línea export que debes añadir a tu perfil.

Binarios de la release

Descarga el archivo de la plataforma desde la página de releases, junto con SHA256SUMS.txt. En Linux o macOS:

version=0.1.0
target=x86_64-unknown-linux-gnu      # o aarch64-unknown-linux-gnu, x86_64-apple-darwin…
base="https://github.com/jhonwick20262027-boop/rukito/releases/download/v$version"
asset="rdd-$version-$target.tar.gz"

curl -fsSLO "$base/$asset"
curl -fsSLO "$base/SHA256SUMS.txt"
grep -E "(^| )\*?$asset$" SHA256SUMS.txt | sha256sum -c -
tar -xzf "$asset"
mkdir -p "$HOME/.local/bin"
install -m 0755 "rdd-$version-$target/rdd" "$HOME/.local/bin/rdd"
rdd --version

En Windows, con PowerShell:

$version = '0.1.0'
$target = 'x86_64-pc-windows-msvc'
$base = "https://github.com/jhonwick20262027-boop/rukito/releases/download/v$version"
$asset = "rdd-$version-$target.zip"

Invoke-WebRequest -UseBasicParsing "$base/$asset" -OutFile $asset
$sums = (Invoke-WebRequest -UseBasicParsing "$base/SHA256SUMS.txt").Content
if ($sums -is [byte[]]) { $sums = [System.Text.Encoding]::UTF8.GetString($sums) }
$expected = ($sums -split "\r?\n" |
  Where-Object { $_ -match "\s\*?" + [regex]::Escape($asset) + "$" } |
  Select-Object -First 1) -split '\s+' | Select-Object -First 1
if ((Get-FileHash -Algorithm SHA256 $asset).Hash -ne $expected) { throw 'checksum incorrecto' }
Expand-Archive $asset -DestinationPath .
Copy-Item "rdd-$version-$target/rdd.exe" "$env:LOCALAPPDATA\rdd\bin\rdd.exe"
rdd --version

Los checksums se calculan sobre el archivo comprimido, no sobre el ejecutable extraído. En macOS, sha256sum no viene de fábrica: usa shasum -a 256 -c - en su lugar. Si un hash no coincide, no lo ejecutes: vuelve a descargarlo desde la release oficial.

Con cargo

Con una toolchain de Rust 1.94 o superior instalada:

rustup update stable
cargo install rdd-cli

Para trabajar sobre el propio framework, desde un clon del repositorio:

git clone https://github.com/jhonwick20262027-boop/rukito
cargo install --path rukito/crates/rdd-cli

El binario queda en ~/.cargo/bin, que rustup ya añade al PATH. Para actualizar, repite el comando con --force.

Si lo que vas a crear es una aplicación y no usar la CLI, la biblioteca se declara con el paquete publicado y el alias rdd; las rutas ::rdd:: que generan las macros siguen siendo válidas (RA-013):

[dependencies]
rdd = { package = "rdd-framework", version = "0.1" }

Verificar, actualizar y desinstalar

rdd --version    # rdd 0.1.0
rdd --help
TareaInstaladorcargo
ActualizarVuelve a ejecutar el instalador; sin RDD_VERSION toma la última release.cargo install rdd-cli --force
DesinstalarBorra rdd de ~/.local/bin o %LOCALAPPDATA%\rdd\bin; en Windows quita también el directorio del PATH del usuario.cargo uninstall rdd-cli
Versión concretaRDD_VERSION=v0.1.0 o -Version v0.1.0cargo install rdd-cli --version 0.1.0

Problemas comunes

SíntomaCausa y solución
arquitectura no soportadaWindows ARM64 y arquitecturas de 32 bits no tienen binario todavía. Usa cargo install rdd-cli.
rdd: command not foundEl directorio de instalación no está en el PATH. En Unix añade la línea export que imprime el instalador; en Windows abre una terminal nueva.
checksum incorrectoLa descarga se corrompió o un proxy la alteró. Repite la descarga o usa el binario de la release con verificación manual.
no se pudo resolver la última versiónTodavía no hay una release publicada, o la API de GitHub no es accesible (red corporativa o límite de peticiones). Fija RDD_VERSION y descarga el archivo directamente.
macOS bloquea el ejecutable descargado con el navegadorEl instalador usa curl y no marca cuarentena. Si descargaste el zip con el navegador, ejecuta xattr -d com.apple.quarantine "$(command -v rdd)".
El binario de Linux no arranca en una distribución antiguaSe compila en Ubuntu 22.04 (glibc 2.35). En sistemas anteriores usa cargo install rdd-cli.
