Framework REST para Rust

Construye APIs con dominio claro.

rdd combina diseño guiado por dominio con una base ligera y tipada para crear servicios HTTP en Rust.

Empezar con la guía Explorar arquitectura
$ cargo install rdd-cli
Rust 
rdd new mi-api
cd mi-api
rdd g module tareas
rdd run
